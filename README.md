# Identity & Access Standards Notes

デジタルアイデンティティ、認証、認可、API セキュリティ、プロビジョニングに関する標準仕様を、実装者向けに整理する日本語ブログです。

## Editorial principles
- 一次資料（IETF / RFC Editor、OpenID Foundation、W3C など）を優先
- Draft / Final / Recommendation / RFC / BCP などのステータスを明記
- 仕様上の要求と実装上の推奨を分離
- MUST / SHOULD / MAY の強度を崩さない
- 各記事に最終確認日と参照仕様を記載
- 仕様更新時は既存記事も追記・訂正

## Publishing
GitHub Pages / Jekyll 向けの構成です。Settings → Pages で `main` ブランチの `/` (root) を公開ソースに指定してください。

> GitHub Pages は private repository をソースにしても公開サイトになる場合があります。機密情報は置かないでください。

## Scope
OAuth / OpenID Connect / FAPI / WebAuthn / SCIM / SAML / JOSE / DPoP / mTLS / RAR / identity assurance / access control policy など。
